Our World Food Festival - student writing helper

[바로 사용]
Our_World_Food_Festival_App.html 파일을 Chrome 또는 Edge에서 더블클릭해 여세요. 인터넷 연결 없이 기본 활동을 사용할 수 있습니다. 음성 읽기는 브라우저가 제공하는 영어 음성을 사용하므로 기기마다 다를 수 있습니다.

[온라인 배포]
index.html과 assets 폴더를 같은 위치에 두고 GitHub Pages에 업로드합니다. ZIP 파일에는 웹 배포용 버전이 포함되어 있습니다.

[학생 활동]
1. Choose Food: 24개 음식 또는 직접 입력
2. Words & Sentences: 음식별 재료/맛 어휘와 Basic, Challenge, Advanced 수준별 문장틀
3. Plan & Write: 글쓰기 계획, 초안, 자기점검, 동료 피드백, 수정본 작성 및 다운로드
4. Talk & Share: 짝 인터뷰와 자유 인터뷰 질문/대답 연습, 새로 알게 된 정보 기록

[개인정보]
서버나 계정은 사용하지 않으며 학생의 글은 사용 중인 브라우저의 로컬 저장 공간에 자동 저장됩니다. 공용 기기에서는 파일로 내보낸 뒤 Start over로 데이터를 지우세요. 데이터는 자동으로 교사에게 전송되지 않습니다.

[주의]
음식의 재료와 맛은 일반적인 예시이므로 학생이 조사한 정확한 내용만 선택하게 해주세요. 사진은 실제 음식 사진이 아니라 실사 스타일의 AI 제작 이미지입니다.
